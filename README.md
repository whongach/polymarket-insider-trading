# Detecting Insider Trading on Polymarket

Bachelor thesis: Detecting Insider Trading on Polymarket
Frankfurt School of Finance & Management, June 2026
Author: William Hongach
Supervisor: Prof. Co-Pierre Georg

## Contents
- event_study.ipynb — full event study analysis, creation of charts
- contracts.xlsx — contract metadata, group assignments, t=0 dates

## Data
On-chain transaction data retrieved from Dune Analytics (dune.com).
Requires Dune API access to replicate data collection.
Analysis runs on the exported CSV loaded in the notebook.

## Requirements
Python 3.x, pandas, numpy, scipy, matplotlib
